# Winnie's Diary - Personal Portfolio

A responsive personal portfolio website for Winnie Song, created for a GitHub Pages assignment.

## Included sections

- Personal statement
- Professional skills
- Three selected projects
- Live performance photography gallery

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `personal-portfolio`.
2. Upload every file and folder in this package. Keep the `assets` folder structure unchanged.
3. Open the repository's **Settings** page and select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait a few minutes. GitHub will display the live website URL on the Pages settings screen.

Submit both the public repository URL and the live GitHub Pages URL for the assignment.
